# Fast Frame Windows

A Geode mod by jaxer14 for Geometry Dash 2.2081 and Geode 5.11.2. It measures how many frames you had for every click, in red (earlier) and blue (later).

## Build
1. Push this folder to a GitHub repository.
2. Run **Build mod** in the Actions tab.
3. Download **Build Output** and put the `.geode` file in `%LOCALAPPDATA%\GeometryDash\geode\mods`.

## Use
Play a level, pause, press the red **FW** button, then **Analyze**.

## Settings
- **Record runs**: keeps your clicks and game state around them while you play.
- **Largest window measured**: the most frames earlier and later each click is tested.
- **Look-ahead frames**: how long the player has to survive after a click.
